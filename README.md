# SC Ladder Co-op Raid

스타크래프트 래더 점수로 보스를 잡는 협동 레이드 운영판입니다.

https://rairen.github.io/SC_Ladder_Co-op_Raid/

## 사용법

1. 운영자가 보스 이름과 난이도를 정하고 **레이드 시작** (파티원은 비워둬도 됩니다)
2. 스트리머는 각자 **레이드 참가**에 방송 이름을 넣고 참가
3. 래더가 끝날 때마다 승리/패배와 점수 변동값을 입력
4. 별풍선 룰렛은 **룰렛 돌리기**, 잘못 넣은 기록은 **전투 기록**에서 취소

참가하면 그 브라우저에서는 자기 결과와 룰렛만 입력됩니다. **내 입력 링크 복사**로 받은 주소(`?me=이름`)로 들어오면 다음 방송부터 바로 내 이름으로 열립니다.
끝난 레이드는 **레이드 기록**에 남고, **명예의 전당**에서 파티원별 누적 기록을 볼 수 있습니다.
주소 끝에 `?room=코드`를 붙이면 레이드를 따로 저장할 수 있습니다.

### 방송 오버레이
주소 끝에 `?overlay=1`을 붙이면 보스 체력바만 보이는 투명 배경 화면이 됩니다. OBS 브라우저 소스에 넣어 쓰세요. `&rage=0`을 붙이면 분노 게이지를 숨깁니다.

## 규칙

| 항목 | 내용 |
|---|---|
| 보스 HP | 파티 인원 × 1인당 HP |
| 분노 최대치 | 파티 인원 × 1인당 분노 한도 |
| 승리 | 획득 점수만큼 데미지 (멀티 확보 ×1.5, 같은 빌드 연속 ×0.5, 금지 빌드 0) |
| 패배 | 잃은 점수만큼 분노 증가 |
| 광폭화 (HP 50% 이하) | 패배 시 잃은 점수 × 회복률만큼 보스 회복 |
| 체인 보너스 | 서로 다른 3명 연속 승리 시 보스 HP 2% 추가 |
| 성공 / 실패 | 보스 HP 0 / 분노 게이지 가득 |

| 난이도 | 1인당 HP | 1인당 분노 | 광폭화 회복률 |
|---|---|---|---|
| 라이트 | 150 | 160 | 50% |
| 노멀 | 240 | 120 | 100% |
| 하드 | 360 | 80 | 150% |
| 커스텀 | 직접 입력 | 직접 입력 | 직접 입력 |

### 별풍선 룰렛

| 등급 | 확률 | 효과 |
|---|---|---|
| 꽝 | 30% | 없음 |
| 일반 | 40% | 보스 HP 2% 감소 / 분노 5% 감소 |
| 희귀 | 20% | 다음 판 데미지 2배 / 다음 판 패배 보호 |
| 전설 | 5% | 보스 HP 7% 감소 / 도전 미션 (유닛 1종 금지, 승리 시 3배) |
| 함정 | 5% | 보스 HP 4% 회복 / 분노 7% 증가 |
