# 래더 협동 보스 레이드

스타크래프트 래더 점수로 보스를 잡는 협동 레이드 운영판입니다.

https://rairen.github.io/SC_Ladder_Co-op_Raid/

## 사용법

1. 운영자가 보스 이름과 난이도를 정하고 **레이드 시작** (파티원은 역할과 함께 한 명씩 미리 넣거나 비워둬도 됩니다)
2. 스트리머는 각자 **레이드 참가**에 방송 이름을 넣고 참가
3. 래더가 끝날 때마다 승리/패배와 점수 변동값을 입력
4. 별풍선 룰렛은 **룰렛 돌리기**, 잘못 넣은 기록은 **전투 기록**에서 취소

참가하면 그 브라우저에서는 자기 결과와 룰렛만 입력됩니다. **내 입력 링크 복사**로 받은 주소를 즐겨찾기해 두면 다음 방송부터 바로 내 이름으로 열립니다.
레이드가 끝나면 운영자가 **레이드 초기화**로 정리하고 새 레이드를 엽니다. 끝난 레이드는 **레이드 기록**에서 줄을 눌러 파티원별 기록과 전투 기록을 다시 볼 수 있고, **명예의 전당**에서 파티원별 누적 기록을 볼 수 있습니다.

### 방송 오버레이
상단 **방송 오버레이** 버튼에서 **보스 체력바** 또는 **보스 스킬 목록** 화면을 고르고, 주소를 복사해 OBS 브라우저 소스에 넣으세요. 배경은 투명합니다.

## 정보·설정 창

보스 정보 옆 **정보·설정** 버튼에서 보스 스킬, 역할 스킬, 입장료·장비, 규칙·난이도(클리어 시간 계산 포함), 룰렛 확률과 기획안, 레이드 설정을 모두 볼 수 있습니다.

## 레이드 설정

**정보·설정** 창의 **레이드 설정**과 **입장료·장비** 탭에서 운영자가 레이드마다 바꿀 수 있습니다: 승리 유형 배율, 체인 보너스, 입장료 게이지 계수, 별풍선 룰렛 확률, 장비 단계별 필요 입장료와 수치. 저장하면 지금까지의 기록도 새 설정으로 다시 계산됩니다.

## 규칙

| 항목 | 내용 |
|---|---|
| 보스 HP | 1인당 HP × 인원 + 인원당 추가 HP × (인원 − 1) |
| 분노 | 보스가 받은 데미지 × 상승률(0.5)만큼 증가, 최대치는 난이도별 고정 |
| 승리 | 획득 점수만큼 데미지. 승리 유형 선택: 일반 ×1, 운영 승리(멀티 확보) ×1.5, 빌드 반복 ×0.5, 초반 올인 ×0 |
| 패배 | 분노 변화 없음, 스킬 게이지 충전 |
| 보스 회복 (HP 50% 이하) | 패배 시 잃은 점수 × 회복률만큼 보스 회복 |
| 체인 보너스 | 서로 다른 3명 연속 승리 시 보스 HP 2% 추가 |
| 분노 게이지 가득 | 보스 스킬 1회 무작위 발동 후 게이지 초기화 |
| 파티원 체력 | 1인당 100, 0이 되면 전투불능 (승리 시 체력 30으로 부활, 그 판은 데미지 없음) |
| 성공 / 실패 | 보스 HP 0 / 파티 전원 전투불능 |

### 난이도

보스 HP = 1인당 HP × 인원 + 인원당 추가 HP × (인원 − 1)
예: 라이트 2인 = 120 × 2 + 10 × 1 = 250

| 난이도 | 1인당 HP | 인원당 추가 HP | 분노 최대치 | 회복률 |
|---|---|---|---|---|
| 라이트 | 120 | 10 | 100 | 25% |
| 노멀 | 220 | 20 | 80 | 40% |
| 하드 | 280 | 30 | 60 | 60% |
| 커스텀 | 직접 입력 | 직접 입력 | 직접 입력 | 직접 입력 |

보스 HP가 50% 아래일 때는 패배 점수 × 회복률만큼 보스가 회복합니다.

### 보스 스킬

보스마다 종족별 스킬 세트를 가집니다. 보스 정보의 **정보·설정** 버튼에서 확인하고, 운영자는 스킬 이름, 종류, 비중, 수치를 고치거나 추가·삭제할 수 있습니다.

| 종족 | 스킬 |
|---|---|
| 저그 | 급속 재생, 산성 침, 감염 확산, 기생 |
| 프로토스 | 보호막 충전, 사이오닉 스톰, 정신 지배, 차원 재생 |
| 테란 | 긴급 수리, 야마토 포, 핵 공격, 방어 매트릭스 |
| 혼합 | 재생, 강타, 광역 화염, 저주, 보호막 |

### 파티 역할과 스킬 게이지

참가할 때 역할과 입장료를 고릅니다. 스킬 게이지는 시작 20에서 승리 +25, 패배 +15씩 차고, 필요 게이지에 닿으면 역할 스킬을 쓸 수 있습니다.

필요 게이지 = 100 − 입장료 × 0.001 (예: 입장료 1,000개면 99)

| 역할 | 기본 스킬 | 효과 |
|---|---|---|
| 탱커 | 도발 | 다음 보스 공격을 혼자 받고 피해 50% 감소 |
| 딜러 | 집중 포화 | 보스 HP 5% 즉시 감소 |
| 힐러 | 치유의 빛 | 파티원 전원 체력 +30 (전투불능도 부활) |
| 서포터 | 전투 자극 | 파티의 다음 승리 2번 데미지 ×1.5, 저주 해제 |

### 입장료와 장비

입장료(그 파티원 방송에서 받은 레이드 입장 별풍선)에 따라 장비가 정해집니다. 착용 중인 장비는 파티 현황과 결과 입력 칸에 표시됩니다.

| 입장료 | 무기 | 갑옷 | 장신구 |
|---|---|---|---|
| 0 | 낡은 검 | 천 옷 | 없음 |
| 100 | | 사슬 갑옷 (체력 +20) | |
| 300 | 강철 검 (데미지 +10%) | | 평온의 부적 (내 공격 분노 −10%) |
| 500 | | 판금 갑옷 (체력 +50) | |
| 1000 | 마력 검 (데미지 +25%) | | 불사의 목걸이 (1회 버팀) |
