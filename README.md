# SC Ladder Co-op Raid (BETA)

스타크래프트 래더 점수로 가상의 보스를 잡는 SOOP 방송용 협동 레이드 운영판입니다.

## 베타 버전 사용법

베타는 서버 없이 **운영자 한 명의 브라우저에 기록이 저장**되는 방식입니다.
파티원은 각자 방송에서 래더를 돌리고, 결과(점수 변동)를 운영자에게 알려주면 운영자가 입력합니다.

1. 페이지를 열면 레이드 설정 창이 뜹니다. 보스 이름, 파티원, 난이도를 정하고 **레이드 시작**
2. 래더가 끝날 때마다 파티원을 고르고 승리/패배와 점수 변동값을 입력 → **결과 반영** (Enter 가능)
3. 별풍선 룰렛은 해당 파티원을 고른 뒤 **룰렛 돌리기**. 다른 룰렛 툴을 썼다면 "결과 직접 입력" 사용
4. 잘못 넣은 기록은 **전투 기록**에서 취소

### 저장과 백업
- 새로고침하거나 브라우저를 껐다 켜도 기록이 유지됩니다(같은 브라우저 기준).
- 같은 브라우저에서 탭을 하나 더 열면 그 탭에도 자동 반영됩니다. 입력용 탭과 방송 화면용 탭을 나눠 쓸 수 있습니다.
- 다른 PC로 옮기거나 기록을 남기려면 **백업 저장**으로 .json 파일을 받고, 옮긴 곳에서 **백업 불러오기**를 쓰세요.
- 브라우저 사이트 데이터를 지우면 기록도 사라지니, 방송이 끝나면 백업을 저장해 두는 걸 권합니다.

### 방 코드
주소 끝에 `?room=코드`를 붙이면 레이드가 따로 저장됩니다. 예: `.../?room=week2`

## 규칙 요약

| 항목 | 내용 |
|---|---|
| 보스 HP | 파티 인원 × 1인당 HP |
| 분노 최대치 | 파티 인원 × 1인당 분노 한도 |
| 승리 | 획득 점수만큼 데미지 (멀티 확보 ×1.5, 같은 빌드 연속 ×0.5, 금지 빌드 0) |
| 패배 | 잃은 점수만큼 분노 증가 |
| 광폭화 (HP 50% 이하) | 패배 시 잃은 점수 × 회복률만큼 보스 회복 |
| 체인 보너스 | 서로 다른 3명 연속 승리 시 보스 HP 2% 추가 |
| 성공 / 실패 | 보스 HP 0 / 분노 게이지 가득 |

| 난이도 | 1인당 HP | 1인당 분노 | 광폭화 회복률 |
|---|---|---|---|
| 라이트 | 150 | 160 | 50% |
| 노멀 | 240 | 120 | 100% |
| 하드 | 360 | 80 | 150% |
| 커스텀 | 직접 입력 | 직접 입력 | 직접 입력 |

## 다음 단계 (실시간 공유 버전)

`config.js`와 `database.rules.json`은 Firebase 연동용으로 남겨둔 파일입니다. 베타에서는 쓰이지 않습니다.
파티원 각자가 직접 입력하는 공유 버전으로 갈 때 Firebase Realtime Database를 연결할 예정입니다.
