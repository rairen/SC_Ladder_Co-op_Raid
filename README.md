# 래더 협동 보스 레이드

스타크래프트 래더 점수로 보스를 잡는 협동 레이드 운영판입니다.

https://rairen.github.io/SC_Ladder_Co-op_Raid/

## 사용법

1. 운영자가 보스 이름과 난이도를 정하고 **레이드 시작** (파티원은 역할과 함께 한 명씩 미리 넣거나 비워둬도 됩니다)
2. 스트리머는 각자 **레이드 참가**에 방송 이름을 넣고 참가
3. 래더가 끝날 때마다 승리/패배와 점수 변동값을 입력
4. 룰렛은 결과를 골라 **결과 반영**(또는 **여기서 룰렛 돌리기**), 잘못 넣은 기록은 **전투 기록**에서 취소

참가하면 그 브라우저에서는 자기 결과와 룰렛만 입력됩니다. **내 입력 링크 복사**로 받은 주소를 즐겨찾기해 두면 다음 방송부터 바로 내 이름으로 열립니다.
레이드가 끝나면 운영자가 보스 정보 옆 **새 레이드 시작** 버튼으로 정리하고 새 레이드를 엽니다. 진행 중에도 **레이드 종료**로 중단할 수 있고, 중단한 레이드는 기록에 "중단"으로 보관됩니다. 끝난 레이드는 **레이드 기록**에서 줄을 눌러 파티원별 기록과 전투 기록을 다시 볼 수 있고, **명예의 전당**에서 파티원별 누적 기록을 볼 수 있습니다.

### 래더 점수 자동 수집
파티원 래더 아이디를 **래더 자동 수집** 칸(또는 참가할 때)에 넣고, 스타크래프트: 리마스터에 로그인한 PC 한 대에서 [수집기](collector/ladder-collector.cmd)를 실행하면 래더 한 판이 끝날 때마다 승패와 점수 변동이 자동으로 들어갑니다. 다른 파티원의 점수도 그 PC 한 대가 아이디로 조회합니다. Firebase 연결이 필요하고, 승리 유형은 전투 기록에서 고릅니다.

### 방송 오버레이
상단 **방송 오버레이** 버튼에서 **보스 체력바** 또는 **보스 스킬 목록** 화면을 고르고, 주소를 복사해 OBS 브라우저 소스에 넣으세요. 배경은 투명합니다.

## 정보 보기

보스 영역의 **보스 스킬 / 역할 스킬 / 장비 / 룰렛 / 규칙** 버튼으로 진행 중인 레이드의 정보를 볼 수 있습니다. 규칙에는 클리어 시간 계산기가 들어 있습니다.

## 수치 설정

새 레이드 만들기 화면의 **수치 설정**에서 레이드를 시작하기 전에 바꿀 수 있습니다: 보스 스킬(이름·종류·비중·수치), 역할 스킬과 게이지, 장비 룰렛 비용·확률·장비 수치, 승리 유형 배율, 체인 보너스, 입장료 게이지 계수, 룰렛 확률. 레이드를 시작하면 수치는 고정되고, 다음 레이드에서 다시 바꿀 수 있습니다.

## 규칙

| 항목 | 내용 |
|---|---|
| 보스 HP | 1인당 HP × 인원 + 인원당 추가 HP × (인원 − 1) |
| 분노 | 보스가 받은 데미지 × 상승률(0.5)만큼 증가, 최대치는 난이도별 고정 |
| 승리 | 획득 점수만큼 데미지. 승리 유형 선택: 일반 ×1, 운영 승리(멀티 확보) ×1.5, 빌드 반복 ×0.5, 초반 올인 ×0 |
| 패배 | 분노 변화 없음, 스킬 게이지 충전 |
| 보스 회복 (HP 50% 이하) | 패배 시 잃은 점수 × 회복률만큼 보스 회복 |
| 체인 보너스 | 서로 다른 3명 연속 승리 시 보스 HP 2% 추가 |
| 분노 게이지 가득 | 보스 스킬 1회 무작위 발동 후 게이지 초기화 |
| 파티원 체력 | 1인당 100, 0이 되면 전투불능 (승리 시 체력 30으로 부활, 그 판은 데미지 없음) |
| 성공 / 실패 | 보스 HP 0 / 파티 전원 전투불능 |

### 난이도

보스 HP = 1인당 HP × 인원 + 인원당 추가 HP × (인원 − 1)
예: 라이트 2인 = 120 × 2 + 10 × 1 = 250

| 난이도 | 1인당 HP | 인원당 추가 HP | 분노 최대치 | 회복률 |
|---|---|---|---|---|
| 라이트 | 120 | 10 | 100 | 25% |
| 노멀 | 220 | 20 | 80 | 40% |
| 하드 | 280 | 30 | 60 | 60% |
| 커스텀 | 직접 입력 | 직접 입력 | 직접 입력 | 직접 입력 |

보스 HP가 50% 아래일 때는 패배 점수 × 회복률만큼 보스가 회복합니다.

### 보스 스킬

보스마다 종족별 스킬 세트를 가집니다. 보스 영역의 **보스 스킬** 버튼에서 확인하고, 레이드 시작 전 **수치 설정**에서 고치거나 추가·삭제할 수 있습니다.

| 종족 | 스킬 |
|---|---|
| 저그 | 급속 재생, 산성 침, 감염 확산, 기생 |
| 프로토스 | 보호막 충전, 사이오닉 스톰, 정신 지배, 차원 재생 |
| 테란 | 긴급 수리, 야마토 포, 핵 공격, 방어 매트릭스 |
| 혼합 | 재생, 강타, 광역 화염, 저주, 보호막 |

### 파티 역할과 스킬 게이지

참가할 때 역할과 입장료를 고릅니다. 스킬 게이지는 시작 20에서 승리 +25, 패배 +15씩 차고, 필요 게이지에 닿으면 역할 스킬을 쓸 수 있습니다.

필요 게이지 = 100 − 입장료 × 0.001 (예: 입장료 1,000개면 99)

| 역할 | 기본 스킬 | 효과 |
|---|---|---|
| 탱커 | 도발 | 다음 보스 공격을 혼자 받고 피해 50% 감소 |
| 딜러 | 집중 포화 | 보스 HP 5% 즉시 감소 |
| 힐러 | 치유의 빛 | 파티원 전원 체력 +30 (전투불능도 부활) |
| 서포터 | 전투 자극 | 파티의 다음 승리 2번 데미지 ×1.5, 저주 해제 |

### 입장료와 장비 룰렛

입장료(그 파티원 방송에서 받은 레이드 입장 별풍선)는 장비 룰렛에 쓰는 잔액입니다. **장비 룰렛**을 한 번 돌릴 때마다 100이 빠지고, 아래 확률로 장비를 얻습니다. 지금보다 좋은 장비면 바로 장착하고, 착용 중인 장비는 파티 현황과 결과 입력 칸에 표시됩니다. 비용과 확률은 레이드 시작 전 수치 설정에서 바꿀 수 있습니다.

| 결과 | 확률 | 효과 |
|---|---|---|
| 꽝 | 30% | 없음 |
| 강철 검 | 15% | 승리 데미지 +10% |
| 마력 검 | 5% | 승리 데미지 +25% |
| 사슬 갑옷 | 20% | 최대 체력 +20 |
| 판금 갑옷 | 8% | 최대 체력 +50 |
| 평온의 부적 | 15% | 내 공격으로 오르는 분노 −10% |
| 불사의 목걸이 | 7% | 레이드당 1회, 쓰러질 때 체력 30으로 버팀 |

역할 스킬 필요 게이지는 받은 입장료 총액 기준입니다 (100 − 입장료 × 0.001).
