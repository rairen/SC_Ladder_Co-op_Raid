로그인과 개인정보 안내

시행일 2026년 10월 10일

래더 협동 보스 레이드는 방송용 레이드 진행판입니다. 참가와 권한 관리를 위해 구글 로그인을 씁니다. 이 사이트가 다루는 정보와 그 범위를 아래에 안내합니다.

1. 다루는 정보

레이드 기록참가 이름, 역할, 입장료, 래더 결과(승패·점수), 룰렛·장비 기록, 참가한 계정 고유 IDFirebase 데이터베이스

2. 쓰는 목적

  • 본인 확인과 레이드 참가, 내 기록만 입력할 수 있게 하는 권한 관리
  • 운영자 권한 확인
  • 레이드 진행 상황과 기록, 명예의 전당 표시, 방송 오버레이 표시

3. 공개 범위

  • 방송 닉네임, 게임 아이디, 레이드 기록은 사이트를 여는 누구에게나 보입니다. 방송 화면에 띄우는 용도이기 때문입니다. 공개되어도 괜찮은 이름을 쓰세요.
  • 구글 이메일은 화면에 공개되지 않습니다. 다만 사이트 관리자는 Firebase 콘솔에서 로그인한 계정 목록(이메일 포함)을 볼 수 있습니다.
  • 판매하거나 다른 목적으로 제3자에게 제공하지 않습니다.

4. 처리를 맡기는 곳

  • Google Firebase (Google LLC): 로그인 인증과 데이터베이스 저장. 데이터베이스는 Google의 아시아(싱가포르) 서버에 있습니다.
  • GitHub Pages: 사이트 파일 제공. Google Fonts: 글꼴 제공. 이 과정에서 각 서비스가 접속 IP 같은 일반 접속 정보를 받을 수 있습니다.

5. 보관 기간과 삭제

  • 프로필은 직접 고치거나, 프로필 창의 로그인 정보 삭제로 언제든 지울 수 있습니다. 이때 프로필과 구글 로그인 연결이 함께 삭제됩니다.
  • 이미 끝난 레이드 기록(참가 이름과 결과)은 레이드 기록·명예의 전당을 위해 남습니다. 지우고 싶으면 아래로 요청하세요.
  • 사이트 운영을 끝내면 데이터베이스를 삭제합니다.

6. 문의와 요청

열람·수정·삭제 요청이나 문의는 GitHub 이슈로 남기거나 레이드 운영자에게 직접 알려 주세요.

로그인하지 않아도 레이드 진행 화면과 기록은 볼 수 있습니다. 로그인은 레이드에 참가하거나 운영할 때만 필요합니다.
